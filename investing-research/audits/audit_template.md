# Audit scoring template

Score each pillar 0 to 3:
- 0 = absent
- 1 = mentioned but thin, uncited, or outdated
- 2 = adequate: cited, dated, usable by the planner
- 3 = strong: multiple quality sources, numbers with dates, contradictions handled

Pass threshold: every pillar >= 2 AND total >= 38 / 45.

Output format the auditor must produce:

| Pillar | Score | Evidence (file and section) | Gap (if < 3) |
|--------|-------|-----------------------------|--------------|

Then:
- TOTAL: n / 45
- VERDICT: PASS or FAIL
- GAP LIST: numbered, each gap tagged with the research pillar(s) R1-R15 or plan pillar(s) P1-P15 it belongs to, and a one-line instruction for the gap-fill agent.
